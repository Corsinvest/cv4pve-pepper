cv4pve-pepper runs **on the computer where the console should appear** and talks only to the Proxmox VE
REST API. Nothing is installed on the nodes.

## Install remote-viewer

pepper does not draw the console itself: it starts `remote-viewer`, the viewer of the virt-viewer project,
and passes it the connection. Its path is the required `--viewer` option.

<Tabs syncKey="os">
  <TabItem label="Windows">
    ```powershell
    winget install RedHat.VirtViewer
    ```
    The viewer is `C:\Program Files\VirtViewer v<version>\bin\remote-viewer.exe`, e.g. `VirtViewer v11.0-256`.
    The installer is also on the [SPICE download page](https://www.spice-space.org/download.html).
  </TabItem>
  <TabItem label="Debian / Ubuntu">
    ```bash
    sudo apt install virt-viewer    # /usr/bin/remote-viewer
    ```
  </TabItem>
  <TabItem label="RHEL / Fedora">
    ```bash
    sudo dnf install virt-viewer    # /usr/bin/remote-viewer
    ```
  </TabItem>
  <TabItem label="macOS">
    See the [SPICE macOS client page](https://www.spice-space.org/osx-client.html), then pass the path of
    `remote-viewer` to `--viewer`.
  </TabItem>
</Tabs>

## Open a console

```bash
cv4pve-pepper --host=pve01 --api-token='pepper@pve!console=UUID' --vmid=100 --viewer=/usr/bin/remote-viewer
```

On Windows:

```powershell
cv4pve-pepper --host=pve01 --api-token='pepper@pve!console=UUID' --vmid=100 `
  --viewer="C:\Program Files\VirtViewer v11.0-256\bin\remote-viewer.exe"
```

- Without other options pepper opens the **SPICE** console. A VM needs its display set to SPICE for that;
  containers always have it. For any other running VM add `--vnc` — see [SPICE and VNC](/cv4pve-pepper/spice-and-vnc/).
- `--vmid` takes the id or the name of the VM or container — see [Options](/cv4pve-pepper/options/#finding-the-vm-or-container).
- If the guest is stopped, add `--start-or-resume` to start it first.

With SPICE pepper exits as soon as the viewer has started, and the viewer stays open. With `--vnc` pepper
keeps running until you close the viewer, because it carries the console traffic.

When the command works, put it in a [parameter file and a desktop shortcut](/cv4pve-pepper/desktop-shortcut/).
