cv4pve-pepper talks to the Proxmox VE REST API of any node of the cluster. Create the user and API token
first: see [Permissions](/cv4pve-pepper/permissions/).

<CliConnection user="pepper@pve" />

## Options in a file

Every console you open repeats the same connection and viewer path: keep them in a file.

<CliResponseFiles
  tool="cv4pve-pepper"
  user="pepper@pve"
  token="console"
  extra={['# Path of remote-viewer on this computer', '--viewer=/usr/bin/remote-viewer']}
  run="--vmid=100"
/>

For one file per VM, opened from a desktop icon, see [Desktop shortcut](/cv4pve-pepper/desktop-shortcut/).
